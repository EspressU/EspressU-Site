UTool

UTool is what you use to install EspressU on your iPhone or iPad. Get UTool first, then use it to install EspressU.

Install UToolInstall guide
“espressu.github.io” would like to install “UTool”
CancelInstall

This is what Safari shows when you tap Install.

Installing

  1. 1

    Open this page in Safari

    Installing only works in Safari, not in other browsers.

  2. 2

    Tap Install UTool

    After a few seconds iOS asks whether you want to install the app. Tap Install. The app then appears on your Home Screen.

  3. 3

    Trust the developer if asked

    If the app does not open, go to Settings, General, VPN and Device Management, and trust the developer there.
