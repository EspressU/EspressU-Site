Wii U games on your iPhone and iPad

EspressU is a free, open-source Wii U emulator built on Cemu, with a Metal renderer, built-in JIT and controller support.

Download on GitHubInstall guideJoin the Discord

Get it running

You need an iPhone or iPad on iOS or iPadOS 17.4 or later, with Developer Mode turned on.

  1. 1

    Download the IPA

    Get it from the Releases page. The file is unsigned, so it needs to be signed before it installs.

    Download
  2. 2

    Install it with SideInstaller

    SideInstaller signs the app right on your device, so you do not need a computer. It also includes the higher memory limit that most games need.

    SideInstaller
  3. 3

    Set up JIT

    Open Settings, then JIT. Import your pairing file and connect LocalDevVPN. After that JIT starts by itself when you launch a game.

  4. 4

    Add your games

    Use the Add button in the library. You can load .wua files, decrypted folders, or encrypted games with your own keys.txt.

What you get

Metal renderer
Graphics run on Apple's Metal. A persistent shader cache means games compile fewer shaders the next time you play.
Built-in JIT
An ARM64 recompiler for iOS 17.4 and later. Without JIT only the much slower interpreter runs.
Controllers
Play with a DualSense, Xbox or MFi controller, or use the on-screen GamePad and lay it out yourself.
Updates and DLC
Import updates and DLC for your games, and use graphic packs for the ones that have them.

When it breaks

A game closes on its own.

It most likely ran out of memory. Install EspressU with SideInstaller, which raises the limit.

A game is very slow.

JIT is probably off. Check that LocalDevVPN is connected and that the pairing file is imported.

A game will not open.

Encrypted games need your own keys.txt. Games can also be .wua files or decrypted folders.

Are games or keys included?

No. You need your own dumps from your own Wii U.
